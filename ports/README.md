# PORTS

Channels are not stages. A port is a source, a destination, or both, and it is shared
across every loop.

Separating ports from stages is what turns a pile of automations into a system. It is also
why the same LinkedIn connection serves the content loop and the demand loop without
either one owning it.

| Port | Direction | Carries |
|---|---|---|
| LinkedIn | IN + OUT | Out: posts, DMs. In: commenters and what they said. The highest intent free signal available. |
| YouTube | IN + OUT | Out: uploads. In: comments, retention, search terms |
| Email | IN + OUT | Out: sends. In: replies, clicks, unsubscribe reasons |
| Website / CMS | IN + OUT | Out: pages, schema. In: search queries, behaviour |
| GitHub | IN + OUT | Out: skills. In: stars, forks, issues. Every issue is a topic. |
| Sales calls | IN | The highest value signal in most systems and the least wired in |
| Reviews | IN | Objections in the buyer's own words |
| Search tools | IN | Demand, rankings, decay, gaps |
| AI engines | IN | Citations and answer gaps |
| CRM | IN + OUT | Pipeline in, briefs and sequences out |

**The ports that run both directions are the valuable ones.** Output feeds input.
That is "owned distribution compounds," stated mechanically rather than as a slogan.

configured per loop is a port you will maintain four times.
