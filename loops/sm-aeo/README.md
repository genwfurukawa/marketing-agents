# sm-aeo

Getting cited when a buyer asks an AI engine instead of a search engine.

This used to be the whole product. It is now one loop of four, which is the right
size for it: being cited is a distribution channel, not a strategy.

## What it does

**CAPTURE, sensing half.** Run a bank of real buyer questions across engines. Record
who gets cited, who gets recommended instead of you, and which questions return
nobody.

**CAPTURE, judgment half.** Answer gaps become briefs. This is the most direct cross
loop connection in the system: an `sm-aeo` gap becomes an `sm-content` queue item
with no human step between noticing it and having something to write.

**BUILD, APPROVE and SHIP.** Pages built to the structures models actually extract,
checked against the six gates, plus the technical readiness work that decides whether
a crawler can reach you at all.

**IMPROVE.** The same question bank, re-run on a schedule against a day one baseline.
One run is a screenshot. The trend line is the only thing worth reporting.

## The honest framing

Citation share moves slowly and is not fully attributable. Report the delta against
your own baseline rather than an absolute score, and never promise a ranking. Anyone
guaranteeing one is misrepresenting how these systems work.
