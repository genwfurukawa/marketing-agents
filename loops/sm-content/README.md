# sm-content

Briefs to drafts to publication. Volume happens here, which means the gates matter
here most.

## The clocks

CAPTURE runs weekly. BUILD runs daily. Running CAPTURE daily produces a queue nobody
can keep up with and a strategy that changes faster than anything can be measured.

## The rule that governs what gets made

**It starts with real work, a real buyer question, or an observed problem.** If it
did not come from work that happened, it does not get published. Record the source
on every brief. A brief with an empty source field is a brief for a piece nobody
needed.

## What not to make

Kill anything designed for reach. Tool lists, trend takes, roundups, "10 prompts
for marketers." They perform and they bring you nobody.

Every piece should make some readers think *this is not for me*. If it could not,
it was written for everyone, which means it was written for no one in particular.

That is the Fit gate in `../../gates/`, and it rejects more drafts than the other
three combined.

## The formula

**Tactical hook, identity payload.** Link an immediate problem to the deeper outcome.

Not: "here is how to automate content briefs."

Instead: "the reason your best campaign is still in a Google Doc is not the writing.
It is that you are the only one who can approve it. Here is what changes when you
are not."
