## Example: What Good Research Looks Like

### Ahrefs Analysis (10-Minute Deep Dive)

**Channel Stats:**
- 600K subs, 15K avg views = 2.5% engagement
- Uploads 2x/week (consistency pays off)
- Primary format: Tutorials with screen recordings

**Top 5 Videos:**
1. "Keyword Research Tutorial" - 450K views (75% of subs watched)
2. "Link Building Guide" - 380K views
3. "On-Page SEO Checklist" - 320K views
4. "SEO Audit Tutorial" - 290K views
5. "Content Strategy Framework" - 250K views

**Patterns:**
- "How to" tutorials outperform news/opinion (3x views)
- 12-15 min videos perform best (vs. 5 min or 20+ min)
- Thumbnails: Always face + tool screenshot + 3-5 word text
- Titles: Front-load keyword, include year if relevant
- Topics: Fundamentals outperform advanced tactics

**Our Takeaway:**
- Focus on "How to" tutorials first (not news or opinion)
- Aim for 12-15 minute videos
- Use face + screen recording format
- Test thumbnails with similar structure
- Prioritize foundational AEO topics before advanced
