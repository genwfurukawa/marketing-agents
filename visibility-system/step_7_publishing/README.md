# Step 7: Publishing + Sequencing

> **Question**: Is content published with intent, not hope?

## Pipeline Position
- **Receives from**: Step 6 (AEO-optimized content library)
- **Produces for**: Step 8 (Published content URLs + publishing log)
- **Agent**: Manual (no automated agent - coordinate publishing directly)

## Purpose
Publish content strategically with clear roles for each channel and narrative sequencing over time.

## Subfolders

| Folder | What Goes Here |
|--------|---------------|
| `publishing_log/` | What was published, when, where (the record) |
| `narrative_sequences/` | Content arcs and themes over time |
| `channel_strategy/` | Role of each channel (LinkedIn, blog, email, etc.) |
| `calendar/` | Upcoming publishing schedule |

## Checklist
- [ ] Clear roles for each channel
- [ ] Narrative sequencing over time
- [ ] Posting driven by strategy, not availability
- [ ] Timing based on ICP awareness

## Failure Signal
Random posting, algorithm chasing.

## Output
Publishing log and narrative sequencing rules.
